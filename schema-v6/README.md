# Tervyxa Systems Schema V6

Warstwa entity architecture dla SEO, GEO i AI Search.

Założenia:

- jedna główna encja Organization,
- spójny identyfikator firmy,
- brak fikcyjnych danych,
- brak founder/person schema bez potwierdzonych danych,
- rozszerzanie tylko na podstawie publicznych faktów.

Docelowe typy:

- Organization
- WebSite
- WebPage
- Service
- Article
- TechArticle
- BreadcrumbList
- SoftwareApplication (tylko realne narzędzia)
